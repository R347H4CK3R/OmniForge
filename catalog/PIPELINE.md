# IPA project pipeline

Audit snapshot: 8 November 2026. Public projects only; private repository contents are not listed.

The catalog installs separately versioned apps from public release URLs. This page tracks additional projects inspected during the catalog review. Released entries link to permanent public downloads; pending entries still need the checks or release materials described below. Successful compilation is not proof of working gameplay.

- **PocketForge**: [successful build run](https://github.com/R347H4CK3R/PocketForge/actions/runs/42518096757); metadata fixed, fresh native build and archive inspection passed. A compatible open-source distribution is being prepared with required compiler/dependency notices and complete matching sources. This candidate is not yet a public installable release.
- **madeira-cod-test**: [successful build run](https://github.com/R347H4CK3R/madeira-cod-test/actions/runs/40346816186); obsolete PocketForge artifact sharing the PocketForge identity, not a separate Madeira app. Current Madeira development must be reviewed independently.
- **BO2-IOS-CS**: [reviewed runtime release](https://github.com/R347H4CK3R/BO2-IOS-CS/releases/tag/runtime-0.1-build3) includes required notices and complete matching sources. Native startup/config execution was verified against the exact simulator artifact with corrected log capture. No complete BO2 gameplay or physical-device success is claimed; the release has passed automated catalog verification and is listed in the combined source.
- **BO2CS**: [reviewed prototype release](https://github.com/R347H4CK3R/BO2CS/releases/tag/prototype-0.1.0-build1) is public. Native compilation, IPA structure, dependency notices and simulator autotest were verified; the release has passed automated catalog verification and is listed in the combined source.
- **CSNZ-iOS**: [successful build run](https://github.com/R347H4CK3R/CSNZ-iOS/actions/runs/36201512410); CSNZ-iOS-ARM64-runtime. Not yet promoted into a permanent public release; exact dependency provenance, matching source and required notices are under review.

Twenty simulator unit tests passed; physical-device gameplay remains untested.
- **COD4iOS-COD4NS**: [reviewed diagnostic release](https://github.com/R347H4CK3R/COD4iOS-COD4NS/releases/tag/diagnostic-1.0.3-build4) includes the exact matching-source archive. DukeX has historical successful IPA runs but no retained artifacts in the latest inspected run; its copied source references an upstream project rather than this fork. BO2-Native-iOS currently reports source checks without an IPA. Madeira's canonical release feed is empty. StrataForge-Playport and piper-objc have no successful app-release run in this audit. Android packages are separate from the iOS catalog.

The current installable catalog and detailed app cards are in [Chris's Apps](APPS.md). This pipeline is not an install source and does not publish build-artifact download URLs.
